The app does not ask for your name, email address, phone number or similar details. It has no sign-up or login, ads, usage analytics tools or in-app purchases. Janggi lessons, puzzles, AI games and game review all run on your device. Information leaves your device only when you use the features described below.

## 1. Service and Information Processed

With this app you can learn Janggi through puzzles and games against the AI. You can also play online against other users in a friend room or through random matching. Online games and app error reporting need an internet connection.

| Information processed | Where it is processed and why |
| --- | --- |
| Lesson and puzzle progress, saved game records (the 50 most recent games), AI game and spectating settings, language setting | Stored in the app's settings storage on your device. It is not sent to the developer's server. |
| Room code, game and participant identifiers issued by the server, and your chosen rules, piece setup and assist options (hints and undo) | Sent to the server to create, join and match online game rooms. |
| Move details (the piece moved and where it went), board state, game progress and end status, move times and time-limit information | Processed on the server to send your moves to your opponent and run the game. Your opponent in the same game also sees this information. |
| App error information (error type and message, stack trace, and technical details such as device, operating system and app version) | Sent to an error reporting service when the app crashes or has an error, so we can find and fix the cause (see Section 3). |
| Email address and message content of inquiries | Processed when you contact us by email so we can reply and resolve the issue. |

## 2. Online Games

Online games run through a server operated on Amazon Web Services (Seoul Region, ap-northeast-2). The app talks to the server over HTTPS. Games do not ask for a name or nickname. Each participant is identified only by a random identifier issued by the server. To deliver requests, AWS may process connection information such as IP addresses. The game server does not store this information or use it to identify users.

Anyone who knows a friend room's code can join that room, so share the code only with the person you want to play. If you do not use online games, the information in this section is not sent.

## 3. Error Reporting and International Transfer

To keep the app stable, we use the error reporting service Sentry on Android and iOS. Only app crash and error information is sent. Sentry is configured not to send user identifiers, screenshots, screen recordings, or usage session and performance data. Each time the app runs, the same error is sent only up to a set number of times.

| Item | Details |
| --- | --- |
| Recipient | Functional Software, Inc. d/b/a Sentry |
| Destination country | United States |
| Information transferred | App error information listed in Section 1 |
| When and how | Sent over the internet when an error occurs |
| Purpose | Analyzing the causes of errors and improving app stability |
| Retention period | Up to 90 days (under Sentry's retention policy and project settings) |

Information processed by Sentry is covered by the [Sentry Privacy Policy](https://sentry.io/privacy/). If you do not want error information to be sent, please contact us using the details in Section 6.

## 4. Permissions and External Features

On Android, the app uses only the internet access permission, which online games and error reporting need. On iOS, the app does not request permissions that need separate consent, such as camera, location, photos, contacts or microphone. During a game, the app may use a keep-screen-on feature so the screen does not turn off. This feature does not collect any information.

Tapping a link or the inquiry email address on the app's information screens opens an external browser or email app. Information processed by other apps or websites is covered by those services' own policies.

## 5. Retention and Deletion

1. You can delete information stored on your device by clearing the app's data or uninstalling the app. The app keeps only the 50 most recent game records and deletes older records automatically. Copies made by your operating system's backup and restore features follow that operating system's settings.
2. Online room, matching and game information is used only to run games. The server deletes it automatically 15 minutes after its last update (2 minutes for rooms waiting for an opponent and for random matching). Deleting a room removes its information immediately. Server error logs are kept for 14 days and then deleted.
3. Error information follows the retention period in Section 3.
4. Inquiry emails are kept for 1 year to reply and resolve issues, then deleted. If the law requires a longer retention period, we follow that period.
