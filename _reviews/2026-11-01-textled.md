# 개인정보 처리방침 검토 기록 — 2026-11-01 (빛말)

## 결과와 근거 범위

빛말(`textled`) 한·영 처리방침을 새로 작성했다. 이 기록은 운영자용이며 처리방침 본문이 아니다.

근거는 textled 저장소의 같은 날 작업 트리다. 주요 파일은 `lib/storage/settings.dart`, `lib/storage/library.dart`(기기 저장 항목), `lib/storage/app_storage.dart`·`web_backend.dart`(저장 위치), `lib/platform/`(화면 켜짐·밝기·URL 열기), `docs/decisions.md` D26(웹 전용 글꼴 대체)이다.

## 반영한 내용

- 저장 항목: 문구와 꾸밈 설정, 즐겨찾기(이름·순서)와 최근 50개(마지막 사용 시각), 언어·테마·표시 기본값·잠금 해제 방식·확인한 안전 안내. 서버 전송 없음.
- 저장 위치를 대상별로 적었다: 휴대폰·태블릿 앱 저장소, 데스크톱 앱 데이터 폴더(Linux 예시), 웹은 브라우저 localStorage와 그 삭제 방법.
- 권한 요청 없음, 광고·분석·오류 보고 SDK 없음. 화면 켜짐·밝기 조절은 기기 안에서만 동작하고 표시 종료 시 복원.
- 웹 버전만 번들 글꼴에 없는 글자를 표시할 때 `fonts.gstatic.com`에서 글꼴 파일을 받을 수 있음(D26). Google은 접속 정보를 받고 입력 문구는 받지 않음. 앱(모바일·데스크톱)은 글꼴을 내려받지 않음.
- 문의 처리·권리 행사는 초집중타이머 방침의 문구를 쓰되 개정 방침용 "기존 방침에 따라"는 뺐다. 운영자·보호책임자는 같고, 문의 이메일은 소유자 결정으로 회사 주소 `bizdooroo@gmail.com`(비밀투표·두런두런과 동일)을 쓴다.
- 웹 글꼴 대체는 이용자 브라우저가 Google에 직접 접속하는 것이지만, PIPA 국외 이전 해석 여지를 고려해 받는 자·항목·국가·시점·거부 방법을 표로 적었다.
- 밝기 복원은 표시 종료·앱 이탈 시 이루어지고 비정상 종료 시 즉시 복원되지 않을 수 있음을 적었다(iOS는 시스템 밝기를 바꿈).
- 데스크톱 저장 위치를 Windows·macOS·Linux 모두 적고, 손상 파일 사본(`.bak`)을 언급했다.
- 이용 시 유의사항: 표시 문구의 개인정보 노출 주의, 운전 중 사용·차량 부착 금지.
- 앱 내 링크: 설정 → 개인정보 처리방침이 언어별 페이지(`textled`, `textled_en`)를 브라우저로 연다.

## 확인이 필요한 사항

- 글꼴·문구 팩 내려받기(jsDelivr·GitHub·원 배포처가 IP를 받음)와 QR·링크 공유(카메라 권한, 링크 조각 데이터)는 아직 출시 전이다. 해당 기능을 내보내기 전에 방침을 개정하고 7일 전 안내 규정을 지킨다(textled `todo/packs-assets-repo.md`, `todo/sharing.md`).
- 웹 버전 호스팅 위치가 정해지면 제3조의 "웹 서버" 문장을 구체화한다.
