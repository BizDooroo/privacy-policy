# 플라이트챗(bluechat) 개인정보 처리방침 작성 기록 — 2026-10-27

운영자용 기록이며 처리방침 본문이 아니다.

## 근거

bluechat 저장소의 같은 날짜 작업 트리를 근거로 삼았다. 앱 내장 사본 `assets/legal/privacy_{ko,en}.md`가 원문이고, 이 저장소의 `bluechat.md`, `bluechat_en.md`는 front matter와 언어 전환 링크만 더한 동일 본문이다. 한쪽을 고치면 다른 쪽도 함께 고친다.

| 항목 | 근거 |
| --- | --- |
| 기기 저장 항목 | `lib/data/local_db/app_database.dart` 테이블, `profile_repository.dart` |
| 주변 기기 전송·중계 | `refine.md` relay cache·사진 전송 정책, 초대 QR `invite_payload.dart` |
| 권한 | `AndroidManifest.xml`(SCAN `neverForLocation`, 위치 maxSdk 30), iOS `Info.plist` |
| 만료·삭제 | `kDefaultRoomExpiry` 7일, `kTombstoneTtl` 35일, `cleanupExpired` |
| 오류 보고 | `lib/services/diagnostics/` — 릴리스는 기본 OFF, 동의 시 Dart 오류만, 네이티브 SDK·세션·트레이스 끔, 허용 목록 정제와 식별자 패턴 검사 후 전송 |

## 확인한 외부 설정

- Sentry DSN은 미국 리전 수집 주소다.
- Sentry 프로젝트 `gaerongsalon/bluechat`의 데이터 스크러버는 켜져 있었고, IP 주소 저장 방지(`scrubIPAddresses`)는 꺼져 있어 2026-10-27에 API로 켰다. 처리방침의 "IP를 저장하지 않도록 설정" 문구는 이 설정에 근거한다.
- 요금제별 실제 보관 기간은 확인하지 않았다. 처리방침은 Sentry 공개 기본값(30일 또는 90일)을 인용한다.

## 검토에서 반영한 사항

- Android QR 스캔(mobile_scanner → 번들 ML Kit)은 Google datatransport로 기기·앱 정보, 설치별 식별자, 성능 지표를 Google에 보낸다(병합 manifest의 `MlKitInitProvider`, `CctBackendFactory`). 오류 보고 동의와 무관하게 일어나므로 처리방침 제4조와 Data safety에 공개했다. 원천 제거는 ML Kit 없는 스캐너로 교체가 필요하다.
- 릴리스 오류 보고는 오류 발생 시에만 보낸다. 상태 변화 marker 이벤트(전원 모드, Bluetooth 켜짐·꺼짐 등)는 debug 전용으로 바꿨다.
- 근처 기기의 접속 신호(기기 식별자, 참가 방 식별자, 마지막 신호 시각)를 비참가 기기도 35일 보관하는 점, 중계 저장 기간(방 만료일, 모르면 7일), 알림 내용 표시, 백그라운드 동작, 삭제 시점(앱 실행 시)과 남는 최소 기록, 안전성 확보 조치를 추가했다.
- 오류 보고 동의 창에 받는 곳·국가·시점·방법·보관 기간을 넣었다.

## 남은 운영 확인

- 오류 보고 토글을 포함한 릴리스를 배포하기 전에 이 페이지를 게시한다.
- Google Play Data safety와 App Store App Privacy를 bluechat `store-release/data-safety.md`에 맞춰 갱신하고, 스토어 콘솔의 처리방침 URL을 `https://bizdooroo.github.io/privacy-policy/bluechat`으로 설정한다.
- debug 빌드는 동의 없이 전체 진단(원문 포함)을 보낸다. debug APK는 개발자 소유 기기에만 설치해야 한다.
- Android 자동 백업(allowBackup 기본값)이 켜져 있어 대화가 운영체제 백업에 포함될 수 있다. 처리방침은 백업 포함 가능성을 안내한다. 다른 사람의 중계 캐시가 백업에 포함되므로 `allowBackup=false` 또는 백업 제외 규칙을 검토한다.
- 약관은 설정 화면에서만 열람할 수 있다. 약관규제법상 명시 의무를 강화하려면 온보딩에서 약관·처리방침 링크를 보여 주는 것을 검토한다.
