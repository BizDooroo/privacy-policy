빛말(`textled`) 한·영 이용약관(`textled_terms.md`, `textled_terms_en.md`)을 새로 작성했다. 운영자용 기록이며 약관 본문이 아니다. 법률 자문이 아니다.

근거는 textled 저장소의 2026-11-05 결정 D52(선불 유료 앱, 앱 내 결제 없음, 계정 없음, 웹·데스크톱 미배포, 팩 다운로드의 GitHub 미러)와 `docs/legal-release-checklist.md` §9(콘텐츠 책임, 운전 중 금지, 광과민성), §12(유료 배포 사실), `rules/product.md`(깜빡임 3 Hz 기본 제한)이다.

## 반영한 내용

- 구매·환불은 스토어 정책과 법령 준용, 앱 내 결제 없음, 스토어 계정 귀속으로 iOS↔Android 이전 불가, 가족 공유는 스토어 설정에 따름.
- 사업자 정보는 스토어 상품 페이지 표시로 갈음(공개 저장소에 번호를 두지 않음). 연락처는 이메일만.
- 이용자 책임: 표시·공유 문구, 운전 중·차량 부착 금지, 광과민성, 공유받은 내용 주의, 글꼴 분리 배포 금지(OFL).
- 내려받는 팩: jsDelivr와 GitHub 무료 공개 인프라 의존, 가용성 무보증; 글꼴 라이선스 OFL/Apache, 자체 팩 CC BY 4.0.
- Apple 표준 EULA 우선 조항(App Store Connect의 EULA 필드는 비워 둠 — 커스텀 EULA는 Apple 최소 조건을 담아야 함), 준거법 대한민국, 소비자 분쟁조정 안내.
- 적대적 리뷰 반영: 글꼴 조항을 OFL 재배포 허용과 맞춤(단독 판매만 금지), 보증 배제에 '법이 허용하는 범위' 추가, 약관 변경 7일/30일 사전 고지와 비소급, 사업자 정보는 '스토어에 표시되지 않는 항목은 이메일로 안내'로 서술(Apple은 BRN만 표시 — 통신판매업 신고번호의 iOS 표시 방법은 오너 결정 사항).
